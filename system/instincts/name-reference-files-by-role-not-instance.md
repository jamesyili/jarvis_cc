# Name reference files by role, not instance

Library/reference files should be named for their standing role; the current instance filling that role is content, not filename. Record folders keep instance names — that's what makes them records.

## Evidence

### 2026-08-01 — James's manual writing_style renames (stated preference)

During the people-folder reorg session, James manually renamed the writing_style library and said: "remember this is the type of naming conventions I like."

- `feedback_writing_style.md` → `own_writing_style.md`
- `andrew_writing_style.md` → `aspirational_writing_style.md` (the person moved inside the file; Leo's earlier "one file per person" convention was wrong)
