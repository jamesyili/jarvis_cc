## Evidence

### 2026-05-04
> "Don't write to a doc. Show it here"

Context: Mid-session iterating on Dylan 1:1 prep. James gave Leo a refined operating-model proposal ("Dafang as TL, JJ involved from CG, James contribute in some efforts, Dylan steer"). Leo's prior turn had updated `dylan_1on1_prep_2026-05-05.md` with JJ on Track 3. When James then asked "put it altogether for my Dylan 1:1," Leo's instinct was to update the doc again. James interrupted: "Don't write to a doc. Show it here." Leo's instinct was wrong — James was iterating in real-time, the prior doc was the canonical reference, but he wanted the *consolidated walk-in answer* in chat where he could read it on his phone the morning of the 1:1.

Signal: correction (clear, terse, course-correcting Leo's auto-doc-write reflex).

Related distinction: this is different from end-of-session capture (where doc writes ARE appropriate — the artifact is durable reference for next session). It's also different from creating a NEW doc that didn't exist (often warranted). The pattern fires specifically when James is mid-iteration and wants the *current state* of the synthesis NOW, in chat.

Heuristic: if James is asking for "put it together," "consolidate," "give me the final," "tighten," "what's the answer" — show in chat. If he's asking for "write a doc," "capture this," "save for later," "make it durable" — write to a doc.
