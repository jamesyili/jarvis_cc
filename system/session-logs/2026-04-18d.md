- **pgvector + OpenAI `text-embedding-3-small` (1536-dim)** rejected Rekko's sqlite-vec + 384-dim MiniLM port (D2). Schema-incompatible + quality win is free at MVP scale.
- **ElevenLabs default TTS; Kokoro mac-only dev convenience** (D3). mlx-audio is Apple-Silicon-exclusive; CI runs Linux.
- **Clip selection fails loud, never silently degrades** (D6). `NoMatchError` when no candidate clears threshold — silent degradation is the #1 quality-rot pathway.
- **Whisper added as Step 3.5** (D5 / gap G1). Vision-only retrieval misses speech signal; ~50 LOC for 10x quality on celebrity/news content.
- **Filesystem-first architecture.** JSONL manifests are authoritative; Postgres is a rebuildable index. Drop the DB → `alembic upgrade head` + `db ingest` → full recovery (except embeddings, hence `db-backup.sh`).
- **Branch-per-step git workflow** (D11). Squash-merge to `main`. 6 commits landed, all green.
- **Three-tier test strategy** (D9). Default (mocked) + `-m slow` (real tools against synthetic fixtures) + `-m live` (real APIs). Each catches a class of bugs the tier above can't.
