**Decisions:**

- **`AGENTS.md` is canonical for principles and base context.** Future operating-principle changes go in AGENTS.md, not CLAUDE.md. CLAUDE.md only holds things that don't port to other tools.
- **5 skills flattened, not all 15+.** start/end/prep/draft-email/debrief = the workhorses. Other skills (coach-check, grill-me, thinking-partner, pulse, weekly-review, KB skills, cross-project) stay Claude-only for now — open invite if James wants more.
- **`.claude/skills/<name>/SKILL.md` = source of truth for Claude Code.** Flattened `prompts/*` are derivatives and must be kept in sync on workflow changes. Convention: edit source, then propagate to prompts/.
- **Slash-command references in AGENTS.md get softened, not preserved.** Tool-neutral phrasings only — preserves readability for Codex/Gemini, who have no `/command` system.
