**Decisions:**

- **`/send-me` defaults to HTML rendering, raw markdown opt-in only.** Per Thariq Shihipar's "Unreasonable Effectiveness of HTML in Claude Code" (Anthropic, May 2026): markdown source code looks ugly on Gmail mobile, doesn't scale past ~100 lines, HTML renders natively on any device. Saved as memory so the default is durable across sessions.
- **Migrate off Anthropic-hosted Gmail/Drive MCPs entirely to local Python + Google APIs.** MCP architectural limits (context-size for all content parameters, draft-only, no attachments) made them "not useful for real workflows" per James. Local Python reads from disk directly — zero context cost, real send, real attachments.
- **GCP project = `leo-api`, dedicated scope.** Saved as `reference_gcp_leo_project` memory. Same credentials.json works on PC + Mac; per-machine OAuth tokens.
- **Drive scope = `drive.file` (narrow).** App only sees files it created. Single "Leo Outbox" folder. James's framing: "I just want 1 folder in my drive where I can upload everything."
- **OAuth published to Production status (unverified is fine).** Avoids the 7-day refresh token expiry that Testing-mode-with-sensitive-scopes incurs. One-time "unverified app" warning during first auth, then tokens persist effectively forever.
- **Per-machine OAuth tokens.** Mac authenticates fresh (cleaner, more revocable). credentials.json copies; token.json does NOT.
- **3 templates not 4** for `md_to_html.py` (dropped session_log template — internal continuity material isn't optimized for phone reading). Structured CSS aesthetic (Notion-ish, dense, visual hierarchy) per James's call.
- **Unified `system/outbound_log.md`** (not separate sent_log + drive_log). One row per invocation, kind=gmail|drive column.
