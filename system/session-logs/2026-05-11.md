- **Technical thesis locked: visual user signature as missing primitive.** Pinterest's user-side representations encode visual style implicitly inside opaque multimodal embeddings. VLM-derived interpretable descriptions unlock three things vectors can't: interpretability (readable user-state introspection), auditability (does anticipation match visual style or only topic?), compositionality (mix-and-match style + topic). One primitive, three layers — not three separate projects.
- **4 design decisions locked (Week 1 build-ready):**
  1. **Engagement signal:** saves + closeups (intent-strong, visually-driven). Not clicks. Defer negatives.
  2. **N=50 pins, last 30 days.** Stratified 25 saves + 25 closeups. Tunable in Week 2.
  3. **Synthesis approach: per-pin → aggregate.** Three reasons: interpretability (audit trail), cacheability (hot pins captioned once, reused across users), cost is overstated (~$10 total for V0 sample of 20 users).
  4. **Taxonomy: bottom-up.** Let VLM generate freely Week 1, cluster in Week 1.5, lock controlled vocabulary. Fit to Pinterest's actual visual diversity vs. pre-constrained.
- **Schema designed: structured + narrative hybrid.** YAML structure with `narrative` (3-sentence human read), `structured` (color_palette, composition, mood, content_type, style_tags as feature surface), `derived_from` (reproducibility metadata), `per_pin_captions` (audit trail).
- **Week 2 eval metric refined: taxonomy-axis match aggregation.** For each user, score anticipation's top-K predictions against signature's structured axes. Quantifiable, comparable across users, falsifiable. Tests the hypothesis that anticipation overfits topic and underfits visual style.
- **UPP correctly pulled out of scope.** Leo initially mapped UPP as a downstream feature consumer; James corrected — UPP is foundation pretraining for user representations (Matt Chun PM, Hongtao/Piyush/Rui working group). Visual signature as a downstream feature doesn't belong inside UPP's training task. Different conversation, different timeline.
