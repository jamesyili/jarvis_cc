name: Explain cost and mechanism for remote triggers
description: When proposing remote triggers or cloud-based automation, proactively explain token cost and what needs to be running
type: feedback
---

When proposing remote triggers or any cloud-based automation, proactively explain: (1) what tokens/cost it uses, (2) whether James's machine needs to be on, (3) how to run the same thing locally for free.

**Why:** James asked "what do I turn on?" and "will it burn through my usage?" — meaning the proposal wasn't clear about mechanism or cost. He chose to disable triggers and run locally instead.

**How to apply:** Any time I suggest scheduled/remote work, lead with: "This runs on [where], costs [what], your machine [needs to be on / can be off]. Alternatively, run locally with [command]."
