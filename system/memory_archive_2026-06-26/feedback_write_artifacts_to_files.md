When James asks me to draft substantive artifacts (memos, instructions-to-paste, templates, long specs — anything ~50+ lines of structured content), **write them to files proactively**. Don't keep them conversation-only and wait for James to ask "where did you write these."

**Why:** This session I drafted a paste-ready work-leo prompt and a 2-page BLUF memo entirely in the conversation. When James asked where they were saved, the answer was "nowhere." He then had to re-prompt me to write them with paths I proposed. That's friction on him for work I should have anticipated needed to persist.

**How to apply:**
- Default heuristic: if the output is a **named artifact** (memo, instructions, template, spec, playbook, script, draft email past 3-4 sentences), propose a path and write it.
- Show the content in the response AND write the file — not either/or.
- For BLUF-memo-class drafts with FILL placeholders, mark `v0` or `draft` in filename so status is clear.
- If the path isn't obvious, propose one and write anyway — James will redirect if the location is wrong.
- Small in-conversation drafts (1-2 paragraph talking points, quick Slack replies, code snippets under ~20 lines) stay in conversation — this rule is for persistent artifacts.

**What not to do:** Don't write everything to disk. Quick reactions, coaching dialogue, scratch thinking, transient drafts = stay in conversation. The line is "would James want to find this later?"
