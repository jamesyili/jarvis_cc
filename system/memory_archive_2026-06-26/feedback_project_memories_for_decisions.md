When James makes a significant decision (deprioritization, strategic direction change, scope cut, new commitment), save a project-type memory in addition to updating the source-of-truth file.

**Why:** Source file updates can get missed (as happened 2026-04-04 with rules directory / mgrep). Memory files are loaded automatically at conversation start and act as a cross-check. Without project memories, the only way to recover a missed decision is for James to re-state it — which defeats the purpose of the system.

**How to apply:** After updating the source file, also write a short project memory capturing the decision and its rationale. This is especially important for: deprioritization decisions (easy to forget why something was cut), strategic pivots, and commitments to others (e.g., "committed to Daniel on X by Y date"). Don't over-use — routine task completions don't need a memory, but judgment calls do.
