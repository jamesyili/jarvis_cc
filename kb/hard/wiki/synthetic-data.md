# Synthetic Data for Fine-Tuning

Synthetic data — generated by a model or simulated environment rather than naturally occurring or human-annotated — has become one of the central levers in modern LLM development. Relative to human annotation, it is faster, cheaper, and often achieves higher diversity. It also sidesteps privacy and copyright concerns. The two broad strategies are **distillation from a stronger model** and **self-improvement**, each with distinct tradeoffs.

## Why Synthetic Data Works

The counterintuitive finding from early synthetic data work is that data only half-correct can still be highly useful for instruction-tuning. Synthetic pairs often have correct format and partial correctness even when the answer is wrong — and that is sufficient signal for the model to learn instruction-following behavior. This suggests synthetic data is well-suited for shaping behavior (instruction following, reasoning style) rather than instilling base factual knowledge, where correctness requirements are stricter.

The cost and scalability argument is equally compelling. Alpaca fine-tuned LLaMA-7B on 52k synthetic instruction-response pairs generated from GPT-3.5 for under $500. Phi-1 trained a 1.3B model to write Python functions using "textbook-quality" synthetic data filtered and distilled from GPT-3.5/GPT-4. The data flywheel is real: a model trained on synthetic data can generate better synthetic data for the next iteration.

## Distillation from a Stronger Model

Distillation transfers knowledge and reasoning style from a capable teacher to a more efficient student. The teacher generates labeled examples — instructions, responses, reasoning traces — that are then used to fine-tune the student.

**Self-Instruct (Wang et al., 2022)** is the foundational paper. Starting with 175 human-written seed tasks, GPT-3 bootstraps new instruction-input-output triples via few-shot prompting. A key design decision: tasks are classified as classification vs. non-classification upfront, because classification tasks need an output-first generation approach (generate class labels first, then conditioning input generation on those labels) to avoid label imbalance. ROUGE-L filtering (threshold 0.7) enforces diversity. The resulting 52k instruction dataset improved GPT-3 instruction-following by 33% over the vanilla baseline, nearly matching InstructGPT-001. An ablation confirmed distillation from InstructGPT-003 added another 10%.

**Unnatural Instructions** independently distilled from GPT-3.5, generating 68k instruction-input pairs from 15 human-written seeds via three-shot prompting with nucleus sampling (top-p=0.99). Responses were generated separately with greedy decoding to prioritize correctness. Despite only 56.5% correctness on audit, the resulting T5-LM finetuned model outperformed strong instruction-tuned baselines.

**Key distillation models and their innovations:**

- **Alpaca**: LLaMA-7B on 52k GPT-3.5 generated examples using Self-Instruct seed set. Sub-$500 training cost.
- **Vicuna**: LLaMA fine-tuned on 125k real user conversations from ShareGPT, showing value in naturally diverse human prompts.
- **WizardLM**: Introduced *Evol-Instruct* — systematically increasing instruction complexity via in-depth evolution (add constraints, deepen, add reasoning steps) and in-breadth evolution (topic/skill diversity). The resulting model handles complex queries that simpler distillation misses.
- **Orca**: Augmented instruction-response pairs with GPT-4 *explanation traces* — step-by-step reasoning, "explain like I'm five", "justify your response" — distilling 1M GPT-4 and 5M GPT-3.5 responses. The key insight: smaller models can learn *reasoning process*, not just final answers.
- **Orca 2**: Extended Orca by teaching LLaMA-7B/13B to select the appropriate reasoning strategy (step-by-step vs. recall-then-generate vs. recall-reason-generate) per task type, distilled from 817k GPT-4 samples.
- **Phi-1/Phi-1.5**: Trained on synthetic "textbook-quality" data — GPT-4 annotated educational value scores trained a quality classifier, then GPT-3.5 generated 1B tokens of synthetic textbooks and exercises. Phi-1.5 extended this to 20B tokens of synthetic world-knowledge content.

## Self-Improvement Approaches

Self-improvement bootstraps synthetic data from the model being trained, avoiding external API dependencies and ToS concerns. The tradeoff: bounded by the model's initial abilities, and prone to amplifying biases.

**Instruction Backtranslation (Meta)**: Reverses the usual direction — instead of generating responses for instructions, it generates instructions for human-written web text. A "backward" model trained on seed instruction-response pairs generates candidate instructions for 502k web text segments (CluWeb). A "forward" model then scores each pair 1-5 and selects high-quality examples (≥4). Iterated twice, the resulting Humpback model outperformed all non-distillation methods on AlpacaEval and several proprietary models including Claude and GPT-3.5.

**SPIN (Self-Play Fine-Tuning)**: A GAN-like approach where a discriminator distinguishes human-written from model-generated responses, while the model (generator) learns to make its responses indistinguishable. KL regularization prevents excessive deviation from the initial policy. This creates a self-supervised competitive loop without any external labels.

**Constitutional AI (Anthropic)**: Operates in two stages. In the SFT stage, the model revises its own outputs according to a set of principles (the "constitution"), generating critiques and self-corrected responses. In the RL stage, an AI feedback model trained on the constitution generates preference labels for pairs of model outputs, replacing human preference labelers. CAI combines self-improvement with systematic value alignment.

**Self-Rewarding Language Models**: The model generates its own preference data by rating candidate responses to prompts, then trains on these AI-generated preference pairs via DPO. This creates a data flywheel where reward modeling ability and instruction following improve jointly.

## Synthetic Preference Data for DPO/RLHF

Synthetic data isn't limited to SFT. **Starling-7B** built a synthetic ranking dataset by collecting seven model outputs (from GPT-4, GPT-3.5, Mistral, LLaMA-2) for 183k chat prompts, generating 3.8M pairwise comparisons. A reward model trained on these pairs enabled preference tuning without human raters.

**SteerLM** and **Self-Rewarding** approaches generate preference data through the model's own evaluations, directly enabling DPO-style training from model-generated signal.

## Quality Filtering

Raw synthetic data requires filtering. Common approaches:
- **ROUGE-L deduplication**: Reject new samples with >0.7 longest common subsequence overlap with existing examples (Self-Instruct).
- **LLM-as-judge scoring**: Score pairs 1-5 and retain only high-scoring subsets. Iterated scoring via improved models raises quality over rounds.
- **Heuristic exclusions**: Remove samples with unfulfillable instructions (references to images, pictures), identical input-output pairs, or missing required fields.
- **Quality classifier**: Train a lightweight classifier on GPT-4 educational value annotations (as in Phi-1) to score and filter at scale.

## Data Augmentation as a Complement

Standard data augmentation modifies input format while preserving semantic meaning — text paraphrasing, back-translation, synonym replacement, TF-IDF word swapping. For NLP, UDA (Unsupervised Data Augmentation) showed that augmentation quality matters: semantically valid augmentations (back-translation, TF-IDF replacement) outperform random token perturbation. Augmentation is most valuable when combined with consistency training objectives for semi-supervised settings, and as a preprocessing step for SFT datasets to increase diversity.

## The Synthetic Data Flywheel

The data flywheel dynamic: better models generate better synthetic data, which trains better models. Self-Instruct seeds this with human examples; instruction backtranslation seeds with human-written text; Constitutional AI seeds with a principled value specification. Each iteration improves both data quality and model capability. The limit is that self-improvement cannot transcend the model's own ceiling — distillation from a stronger external teacher breaks through it.

A key risk is that repeated self-improvement can amplify existing model biases and errors. Quality filtering at each iteration (via LLM-as-judge scoring, heuristic checks, diversity filtering) is essential to prevent error accumulation.
