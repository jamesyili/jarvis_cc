> **What this folder is (plan locked 2026-08-01; names per James's role-generic convention, same day):** the foundational reference for how James writes — his own style guide, aspirational styles studied from others, and **one clear exemplar per genre**. Exemplars may be **duplicated copies** of key writings (marked with a banner pointing at the canonical copy); the **comprehensive** collections live in the work tree, one folder per cycle, linked per genre below. ## Conventions

- **Cycle folders are comprehensive by construction:** everything written for a cycle lands in `work/people/downward_reviews/<cycle>/` or `work/people/peer_feedback/<cycle>/` (`h12026`, `h22026`, …). Nothing cycle-specific lives loose in `work/people/`.
- **This folder stays small and curated** — the style guide, the aspirational-styles file, and one strong exemplar per genre. It is voice reference, not a case archive; case records and drafts stay with their cycle.
- **Duplication is deliberate, not drift:** an exemplar copy always carries a banner naming its canonical path and when to refresh it.
- **Freshness:** `example_downward_feedback.md` is a pre-ER-fix snapshot (2026-08-01) — refresh it from `downward_reviews/h12026/` after the week-of-8/10 delivery pass finalizes the canonical copy.
