## 2026-08-14 (eval lane) — the eval curriculum lands; three cheap measurements now specified and unrun

Separate from the Roberto arc above; this is the IC/eval lane. **The eval lane keeps its own docs — start at `eval_00_hub.md`** (state, open items, undelivered critique, IC lane, curriculum index), which points to the four audience-specific docs `eval_01`–`eval_04`. Don't duplicate eval-lane detail into this file.

- **Two new critique items with teeth.** #16: the Evolve Pareto gate's false-accept rate is set by the *unmeasured* correlation among the judge's 5 dimensions — ~3% if independent, toward 50% if they're one factor in five hats. #17: effective n (clustering), minimum detectable effect (~150 paired cases to see 10 points), and CLT failure below n≈100. Neither appears in Chao's proposal or Janvi's TDD.
- **The rubric decision and the gate decision are the same decision.** Implicit aggregation — criteria as inputs to the judge's reasoning rather than five separately-scored axes — is the literature's best-performing configuration *and* it removes the Pareto-correlation problem entirely. Cheaper for Janvi to adopt than the alternative, because it deletes machinery.
- **The hindsight set was reclassified**, from "flagship IC artifact #4" to *the only construct-valid measurement in the program*. Everything else — judge score, human grade, lockbox — measures somebody's opinion of a card. Alarm condition to write into the lockbox doc: **judge fitness rises while hindsight recall stays flat → the loop is optimizing legibility.** It also has a known exposure of its own (the unsupported region: things nobody investigated), which needs salience stratification and an exploration budget.
- **Three measurements are now fully specified, cost almost nothing, and none have been run** — all against judge V1 output that already exists: (1) the 5×5 dimension correlation matrix, (2) per-criterion score variance, to prune non-discriminative metrics empirically instead of arguing about them, (3) the **blind test** — run Detect with Presto/Asana disabled; anything it still produces is measuring the model's recsys priors, not discovery.
